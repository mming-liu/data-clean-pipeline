6本次执行的规则

字段类型化

order_date → 日期；qty → 整数；unit_price、amount → 金额两位小数

枚举归一

status（15 种写法）；region（11 种写法）；category（8 种写法）；channel（9 种写法）

缺失填充

qty ← median；unit_price ← median；region ← mode；category ← mode；channel ← mode；status ← default:待支付；order_date ← mode；customer_phone ← keep

派生列

amount = qty * unit_price

去重

键：order_id；保留策略：most_complete

异常检测

IQR×3.0 标记；业务区间：qty ∈ [1, 5000]；unit_price ∈ [0.01, 100000]；amount ∈ [0, 1000000]

必填校验

order_id、order_date、qty、unit_price

手机号
